- The app checks the project's GitHub page for new versions a few seconds after it starts, then every few hours.
- When there's a new version it downloads it by itself, then shows a box in the corner. Installed with the .exe: click **Restart and install** and it updates and reopens. Mac: click **Install**, then drag Stream Multiview into Applications to replace the old one.
- Settings > Updates shows your version and what's new, lets you check right away, and has the "Update automatically" switch. "Check for updates" in the Help menu (on a Mac, also in the Stream Multiview menu) opens it and checks.
- Your logins, saved channels, layouts and themes are kept. The old app files are backed up first.
- If an update changes the app engine, close the app and start it again with your shortcut. It reinstalls the engine once (about a minute).
