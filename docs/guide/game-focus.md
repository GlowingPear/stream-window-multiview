- Pick Layout > Game focus (or press G). The big area on the left is for your game, everything else goes in the side panel.
- **Put a game here** (Windows): start your game in **Windowed** mode, click **Put a game here** in the game area's bar and pick the game. Its window moves into the game area and stays there when you change the panel size or move Stream Multiview. Click it and play.
  - **No border** hides the game's own title bar so it fills the area. **Play** clicks you into the game. **Release** puts the game back where it was (leaving Game focus or closing the app does this too).
  - If a game won't resize, set it to Windowed mode in its own settings and try again.
- **See-through (play)**: the game area is a see-through hole. Whatever is behind Stream Multiview shows there and you can click into it. (On Linux, put the game behind the app yourself.)
  - "Keep on top" keeps your streams visible when you click into the game.
  - Any window you drag over the game area stays visible on top of the game.
  - Works on Windows (and Linux). On a Mac use "Show a window" instead.
- **Show a window**: put a stream or another app's window in the big area instead, using the dropdown or Pick window. Another app's window is only a picture, so you can't play a game through it.
- S / M / L sets the side panel width, and "Panel left / right" moves it to the other side.
- Pick any other layout to go back to normal.
